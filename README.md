# GSC Analyzer

ابزار تحلیل **Google Search Console** برای سئوکارهای فارسی‌زبان.

داده‌ی سرچ کنسول شما فقط در مرورگر خودتان پردازش و ذخیره می‌شود. این پروژه
بک‌اند ندارد؛ هیچ سطری از داده‌ی شما به هیچ سروری (به‌جز خود گوگل) فرستاده نمی‌شود.

- React + TypeScript + Vite، کاملاً استاتیک
- UI فارسی و RTL با فونت Vazirmatn به‌صورت فایل محلی (بدون CDN)
- ورود با Google Identity Services و دسترسی **فقط‌خواندنی** (`webmasters.readonly`)
- کش داده در IndexedDB تا رفرش صفحه نیاز به دریافت دوباره نداشته باشد

## راه‌اندازی

### ۱) نصب

```bash
npm install
```

### ۲) ساخت OAuth Client ID در گوگل

ابزار برای اتصال به سرچ کنسول به یک Client ID نیاز دارد. یک‌بار این مراحل را انجام دهید:

1. به [Google Cloud Console](https://console.cloud.google.com/) بروید و یک پروژه بسازید (یا یکی را انتخاب کنید).
2. **APIs & Services → Library** → دنبال **Google Search Console API** بگردید و **Enable** را بزنید.
3. **APIs & Services → OAuth consent screen**:
   - نوع **External** را انتخاب کنید.
   - نام اپ و ایمیل پشتیبانی را پر کنید.
   - در مرحله‌ی **Scopes** لازم نیست چیزی اضافه کنید (اپ خودش scope را درخواست می‌کند).
   - در مرحله‌ی **Test users**، ایمیل گوگلی که با آن وارد می‌شوید را اضافه کنید.
     اگر این کار را نکنید، هنگام دریافت داده خطای **۴۰۳** می‌گیرید.
4. **APIs & Services → Credentials → Create Credentials → OAuth client ID**:
   - **Application type**: `Web application`
   - در **Authorized JavaScript origins** این دو را اضافه کنید:
     - `http://localhost:5173`
     - `http://127.0.0.1:5173`
   - نیازی به Authorized redirect URI نیست (این اپ از Token Client استفاده می‌کند).
5. Client ID ساخته‌شده را کپی کنید.

> اگر بعداً روی دامنه‌ی دیگری deploy کردید، همان origin را هم به
> **Authorized JavaScript origins** اضافه کنید.

### ۳) تنظیم Client ID

```bash
cp .env.example .env.local
```

بعد `.env.local` را باز کنید و مقدار را بگذارید:

```
VITE_GOOGLE_CLIENT_ID=123456789-xxxxxxxxxxxx.apps.googleusercontent.com
```

`.env.local` در `.gitignore` است و کامیت نمی‌شود.

### ۴) اجرا

```bash
npm run dev
```

مرورگر را روی <http://localhost:5173> باز کنید.

> **نکته:** آدرسی که باز می‌کنید باید دقیقاً همانی باشد که در
> Authorized JavaScript origins ثبت کرده‌اید. `localhost` و `127.0.0.1` از نگاه
> گوگل دو origin متفاوت‌اند.

## استفاده

1. روی **«اتصال به سرچ کنسول»** بزنید و با حساب گوگلی که به پراپرتی‌ها دسترسی دارد وارد شوید.
2. از فهرست، پراپرتی مورد نظر را انتخاب کنید. پراپرتی‌های Domain با برچسب `Domain` مشخص شده‌اند.
3. ابزار داده‌ی سه ماه گذشته را با ابعاد «صفحه» و «کوئری» می‌گیرد و در جدول نشان می‌دهد.
   برای سایت‌های بزرگ ممکن است چند دقیقه طول بکشد (داده در بسته‌های ۲۵٬۰۰۰ سطری می‌آید).
4. روی عنوان هر ستون بزنید تا مرتب‌سازی عوض شود؛ با جعبه‌ی جست‌وجو می‌توانید در کوئری و آدرس صفحه فیلتر کنید.
5. **«به‌روزرسانی داده»** کش را دور می‌زند و داده را دوباره از گوگل می‌گیرد.
   **«پاک کردن داده‌های محلی»** همه‌ی داده‌ی ذخیره‌شده در این مرورگر را حذف می‌کند.

### بازه‌ی زمانی

پایان بازه **امروز منهای ۳ روز** است، چون داده‌ی سرچ کنسول ۲ تا ۳ روز تأخیر دارد و
روزهای آخر ناقص‌اند. شروع بازه سه ماه قبل از آن است.

### چند نکته که خواندن اعداد را عوض می‌کند

- **میانگین موقعیت وزنی است.** با وزن Impression حساب می‌شود، نه میانگین ساده‌ی ستون موقعیت.
- **جمع کلیک این جدول با آمار کل سایت نمی‌خواند.** حدود ۹۳٪ کلیک‌ها از کوئری‌های
  ناشناس می‌آید که گوگل در بُعد Query گزارش نمی‌کند. برای تحلیل دقیق‌تر، صفحه‌محور نگاه کنید.
- **CTR درصد است.** API عدد اعشاری می‌دهد (`0.048`) و اینجا به‌شکل `۴٫۸۰٪` نمایش داده می‌شود.

## خطاهای رایج

| خطا | معنی | راه حل |
| --- | --- | --- |
| «پیکربندی ناقص است» | `VITE_GOOGLE_CLIENT_ID` تنظیم نشده | `.env.local` را بسازید و سرور dev را دوباره اجرا کنید |
| ۴۰۳ | ایمیل شما در Test users نیست، یا Search Console API فعال نشده | مرحله‌های ۲ و ۳ بالا را دوباره چک کنید |
| ۴۲۹ | سقف نرخ درخواست گوگل | ابزار خودش چند بار با تأخیر تلاش می‌کند؛ اگر نشد چند دقیقه صبر کنید |
| «نشست شما تمام شد» | توکن یک‌ساعته منقضی شده | روی «ورود مجدد به گوگل» بزنید؛ داده‌ی کش‌شده از بین نمی‌رود |
| «اتصال به گوگل برقرار نشد» | دسترسی شبکه به سرویس‌های گوگل | اتصال خود به `googleapis.com` و `accounts.google.com` را بررسی کنید |
| پنجره‌ی ورود باز نمی‌شود | مسدودکننده‌ی پاپ‌آپ | پاپ‌آپ را برای این سایت مجاز کنید |

## build برای انتشار

```bash
npm run build     # خروجی استاتیک در dist/
npm run preview   # پیش‌نمایش محلی همان خروجی
```

محتوای `dist/` را روی هر هاست استاتیکی می‌شود گذاشت. یادتان باشد origin سایت را
به **Authorized JavaScript origins** اپ گوگل اضافه کنید.
